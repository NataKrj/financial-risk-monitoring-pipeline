# Data

This folder contains the public/sample data snapshots used by the portfolio project.

## Raw snapshots

- `accounts.csv` — 7,319 account records.
- `transactions.csv` — 10,000 transaction records.
- `complaints.json` — 2,160 consumer complaint records.

## Processed outputs

- `complaints_clustered.csv` — complaint records with clustering fields and seven consolidated complaint themes.
- `transaction_scenarios.csv` — dashboard alert-event data generated from six core monitoring scenarios.
- `client_risk.csv` — illustrative client-level complaint/alert counts and risk bands.
- `state_risk_summary.csv` — state-level aggregation using only observed complaint geography.
- `dashboard_kpis.csv` — headline metrics used for validation.

## Source references

- IBM AMLSim example dataset: https://www.kaggle.com/datasets/anshankul/ibm-amlsim-example-dataset
- Banking consumer complaint analysis: https://www.kaggle.com/code/shtrausslearning/banking-consumer-complaint-analysis/notebook

No employer, client or confidential information is included.
