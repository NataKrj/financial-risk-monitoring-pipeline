# Tableau dashboard

The final visualisation is included as a packaged Tableau workbook (`.twbx`) and as a static overview image.

**Tableau Public:**  
https://public.tableau.com/views/ComplianceandRiskDashboard-2025/ComplianceandRiskVisualizationDashboardstory

The story includes:
- overall risk/compliance KPIs;
- client risk distribution;
- alert and compliance issue trends;
- state-level mapping;
- scenario-based alert breakdown;
- complaint themes over time.

The Tableau workbook reflects the original visualisation-project snapshot. The portfolio data-preparation script removes random geography imputation used during experimentation, so a fully regenerated geographic view may differ slightly from the original workbook.
